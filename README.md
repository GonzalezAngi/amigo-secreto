# amigo-secreto

Este es un pequeño proyecto en JavaScript que permite gestionar una lista de amigos y realizar un sorteo aleatorio para encontrar quién es tu **amigo secreto**.

## Funcionalidades

- Agregar nombres de amigos a una lista.
- Validar que no se agreguen entradas vacías.
- Mostrar la lista de amigos en pantalla.
- Sortear un amigo secreto de manera aleatoria.
- Mostrar el resultado en la página web.

## Uso

1. Escribe un nombre en el campo de texto.  
2. Haz clic en el botón **"Añadir"** para guardar ese nombre en la lista.  
3. Repite el proceso para agregar más amigos.  
4. Cuando todos los nombres estén en la lista, presiona el botón **"Sortear amigo"**.  
5. Se mostrará el nombre del amigo secreto seleccionado aleatoriamente.
